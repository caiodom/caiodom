## Professional profile

I am a software engineer with **11+ years of experience** and a career progression from hands-on development into senior and specialist-level engineering responsibilities.

My strongest area is backend development with **C# / .NET / ASP.NET Core**, especially systems that require clear boundaries, asynchronous communication, reliability, maintainability, and room to evolve without unnecessary complexity.

Beyond implementation, I work closely with architectural decisions, technical direction, mentoring, and helping teams turn ambiguous requirements into pragmatic software designs.

My engineering approach is based on trade-offs rather than dogma: I value **simple designs, explicit boundaries, automated tests, observability, and architectures that fit the problem instead of the trend**.

## Engineering practices

- **DDD, TDD, SOLID, Clean Code, and design patterns** applied pragmatically.
- Designing APIs and distributed workflows with explicit failure modes and operational concerns in mind.
- Supporting teams with **technical leadership, mentoring, architecture discussions, and code quality decisions**.
- Balancing delivery speed with long-term maintainability instead of optimizing for either extreme.
- Using automation and AI-assisted development to improve research, implementation, debugging, testing, refactoring, and documentation workflows.

## AI-assisted software engineering

I am especially interested in how **LLMs and software agents can become part of repeatable engineering workflows**, not just autocomplete tools.

My current work and experiments explore AI-assisted approaches for:

- technical research and implementation planning;
- code generation and refactoring;
- automated validation and review loops;
- debugging and test generation;
- documentation and engineering knowledge workflows;
- developer productivity and software delivery automation.

The goal is not to replace engineering judgment, but to use AI as leverage while keeping architecture, validation, and technical accountability explicit.
